# 校园失物招领

一个纯前端的「校园失物招领」Web 应用，用户可以在上面集中发布与浏览寻物、招领信息，通过关键词搜索，查看详情与联系方式，并在物品找回或归还后由发布者将信息标记为「已找到」/「已归还」。

- 结对成员：102402126 黄炜杰、102402127 金若曦
- 技术栈：原生 HTML + CSS + JavaScript（无框架），数据存储于浏览器 `localStorage`

### 核心模块说明

- `js/core.js`：与界面解耦的业务层，导出 `LostFound` 对象，包含数据校验、创建信息、搜索、筛选、状态更新、删除、排序等纯函数。该文件在浏览器中以全局对象形式加载，在 Node/Jest 中以 CommonJS 加载，因此可被前端与测试共用。
- `js/app.js`：负责页面渲染与交互，调用 `core.js` 的函数实现完整流程，并负责读写 `localStorage`。
- 数据模型字段：`id` `type`（lost/found）`itemName` `category` `location` `itemDate` `description` `contact` `publisher` `status`（open/resolved）`createdAt`。

## 使用说明

### 运行方式

1. 将整个项目目录下载到本地；
2. 使用谷歌浏览器（Chrome）打开 `index.html` 即可运行，无需联网或安装任何环境；
3. 数据保存在浏览器 `localStorage` 中，刷新页面不会丢失；如需清空数据，清除该站点的 localStorage 即可。

### 功能操作指南

1. **浏览**：首页默认展示全部信息，卡片以「寻物 / 招领」徽章区分，进行中的信息显示彩色徽章、已解决的显示灰色徽章。
2. **搜索**：在顶部搜索框输入物品名称、地点、描述等关键词，点击「搜索」或按回车。
3. **筛选**：可切换「全部 / 寻物 / 招领」标签，也可按类别、地点、状态下拉筛选，多个条件可组合。
4. **发布**：点击导航栏「发布信息」，填写物品名称、类别、地点、时间、描述、联系方式与发布者姓名（带 `*` 为必填），点击「发布」。
5. **查看详情与联系**：点击任意信息卡片进入详情页，可查看完整字段与发布者联系方式，点击「一键复制」复制到剪贴板。
6. **更新状态**：发布者在「我的发布」中输入自己发布时填写的姓名查询，即可对进行中的信息执行「标记已找到 / 已归还」或「删除」；在详情页中，若当前发布者（本地记录的上一个发布姓名）与该信息发布者一致，也可直接操作。
7. **我的发布**：以发布者姓名为维度筛选并管理自己发布的内容。

## 单元测试

项目使用 [Jest](https://jestjs.io/) 进行自动化单元测试，共 21 个测试用例，覆盖输入校验、信息创建、关键词搜索、条件筛选、状态更新、删除、状态文案等核心逻辑。

```bash
# 安装依赖（需本机安装 Node.js）
npm install

# 运行测试
npm test
```

测试针对 `js/core.js` 中的纯函数，采用白盒测试方法，覆盖正常路径、边界输入（空字符串、非法类型、不存在的 id、无匹配结果）以及异常路径（非法输入抛出异常、不可变性验证）。
